# Project instructions

Before working on this project, read `secondBrain/INDEX.md` when it exists.

The `secondBrain/` directory is local project memory and is intentionally
excluded from Git. Use it for durable project context, decisions, conventions,
and user preferences that are likely to matter in future sessions.

When an important, durable piece of project knowledge is established, update
the relevant note in `secondBrain/` briefly and include the date. Do not store
secrets, passwords, tokens, or other sensitive credentials there.

Current user-facing project instructions and the actual source files always
take precedence over notes in `secondBrain/` if they conflict.
